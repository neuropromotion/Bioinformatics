# Техническое задание на 2027–2028 гг.

Приложение к дополнительному соглашению. Полная версия для печати: **`TZ_2027_2028.docx`**.

**Тема НИР:** Установление закономерностей регуляции экспрессионного профиля микроРНК и мРНК в различных типах злокачественной трансформации с помощью молекулярно-биологических методов, а также методов глубинного обучения.

**Проект:** «Онкотераностика и проблемы резистентности к противоопухолевым и антибактериальным препаратам».

## Задачи исполнителя (сжато)

1. DL-модели miRNA по **spatial** RNA-seq (transfer с TabM/TabPack/бустинг; GNN/spatial CNN).
2. DE miRNA и пути в spatial-кластерах (опухоль / иммунитет / stroma).
3. **Перенос** анализа апоптоза и miRNA с scRNA на spatial; spatial-подтипы.
4. **Иммунорезистентные** зоны, ligand–receptor, miRNA и подавление гибели — в spatial-координатах.
5. Связь с **потерей тканевой специфичности** (bulk-задел 2024–2026).
6. **qRT-PCR / ISH** верификация.
7. Открытое ПО и атлас на GitHub.

## Этапы

- **4 (2027):** корпус ≥15 spatial-наборов, модель, пилот ≥4 опухолей, 1 статья, промежуточный отчёт, ЕГИСУ.
- **5 (2028):** ≥25 наборов, атлас, иммунорезистентность spatial, эксперименты, ≥2 статьи, диссертация к.н., заключительный отчёт, ЕГИСУ.
